# NYC rental shortlists and the cost of a stable repair

**Harvard COMPSCI 2880 · Experiment protocol · 7 November 2026**

A renter can see five affordable apartments and still miss the one where both sides would prefer to match. We ask whether the choice of recommender changes how often this happens to lower-income renters. We then ask how much a platform would have to spend to repair the matching while protecting renters who could keep an assignment at least as good as their initial one.

The unit of comparison is an entire market with one slot per listing and at most one assignment per renter. Compare shortlist policies on the same renters, listings, feasible pairs, rankings and per-renter recommendation budgets. Full visibility supplies a separate reference assignment. Changing one renter’s shortlist can change another renter’s assignment.

**First jobs.** Run the tiny-market enumeration and audit the input cohorts. Fit the nine renter specifications on development data, then launch the 300-market pilot in §6. Its variance fixes the main sample size and its token and solver logs determine the cluster reservation.

**Status.** This document specifies prospective NYC experiments. The supplied setup describes an existing runner, 68 passing tests and a laptop runtime estimate. The numerical example in §2 comes from the archived synthetic study. Record the actual NYC runner revision, data hashes, model versions and measured resource use at launch.

## 2. The two quantities to implement first

### Hidden blocking pairs

Let $E$ contain all feasible pairs under the chosen specification. For policy $p$, let $E_0^p$ contain its recommendations and $M_0^p=\mathrm{DA}(E_0^p)$. Use the same strict rankings on every subgraph. Every feasible partner ranks above the outside option.

Set $Y_b^p=1$ if some listing $\ell$ satisfies all three conditions below.

1. $b\ell\in E\setminus E_0^p$.
2. Renter $b$ prefers $\ell$ to $M_0^p(b)$.
3. Listing $\ell$ prefers $b$ to $M_0^p(\ell)$.

Count each renter once. Include zero-option renters with $Y=0$ in the main group denominators and report their prevalence alongside the rates. For group $g$, write $B_g^p$ for the standardized group rate defined in §6. Draw the income boundary once as specified in §3. The primary contrast is

$$
T=(B_{L}^{\mathrm{Claude}}-B_{L}^{\mathrm{uniform}})
 -(B_{H}^{\mathrm{Claude}}-B_{H}^{\mathrm{uniform}}).
$$

Report $100T$ in percentage points and show all four rates. A positive value means Claude widened this modeled disparity relative to uniform recommendations. Also report the contrast among renters with $d>k$ as a conditional result. Renters with $d\le k$ can experience assignment changes through competition. At fixed $d,k$, the number of hidden options is mechanically $d-k$.

Two prespecified diagnostics help interpret this contrast.

- **Opportunity to hide a listing.** Within each group and cell, let $q$ be the share of renters with $d_b>k_b$. Only those renters can have a hidden blocker of their own. The group-cell rate is exactly $q$ times their conditional blocker rate. Show $q$ and the conditional rate alongside the pooled rate. When $q=0$, record zero for the unconditional rate and “undefined” for the conditional rate. This is particularly important in the lowest-income cells, where scarcity can mechanically produce few hidden blockers.
- **Competition across income groups.** Cache each renter’s Claude and uniform shortlists. For every core market run two additional DA assignments, switching just the lower-income group or just the higher-income group to Claude. Denote the standardized lower-minus-higher blocker gap by $Z_{ij}$, with the first index for lower income, the second for higher income, and each index either $C$ (Claude) or $U$ (uniform). Report the four gaps and their group rates. Attribute the change from switching lower-income shortlists as $S_L=[(Z_{CU}-Z_{UU})+(Z_{CC}-Z_{UC})]/2$ and define $S_H=[(Z_{UC}-Z_{UU})+(Z_{CC}-Z_{CU})]/2$. Verify $S_L+S_H=T$ using identical weights and denominators. Each component averages over the two possible switch orders and includes rematching across both groups. Run these as secondary mechanism checks using existing responses and the same seed-block bootstrap. Marketplace interference is a known source of differences between individual and platform-wide effects. [Johari et al., Management Science](https://doi.org/10.1287/mnsc.2021.4247)

Also report the initial matched fraction, fraction assigned one of their top three feasible listings, and the fraction who prefer their full-DA assignment to the initial one, by income group. Treat unmatched as the worst outcome and give the full-market degree distribution alongside rank summaries. For verified repairs report the matched fraction, fraction strictly worse than the initial assignment, and who can change rank across equally cheap plans. Use the policy-specific provisional assignment as the common reference for all of that policy’s repairs.

### The cost of protecting renters

For each realized set of preferences, run renter-proposing DA once on $E$ to obtain $M_E$. Let $D_p(A)$ be DA after auditing firms in $A$ starting from $E_0^p$. Auditing a firm exposes every feasible pair incident to its clients. Initially visible pairs stay visible. Give each renter their own firm, each listing its validated brokerage, and each audit unit cost in the main run. Costs add across audited firms. A plan succeeds when its response has zero blocking pairs on $E$.

For any group $G$, define $H_G(M)=\{b\in G:M(b)\prec_b M_0^p(b)\}$. Every renter weakly prefers $M_E$ to their assignment in every full-market stable matching. Therefore $H_G(M_E)\subseteq H_G(D_p(A))$ for every successful plan. Opening the full graph attains equality. This makes $H_G(M_E)$ the exact set of renters whose losses are unavoidable under the model. All successful repairs also match the same set of renters on a fixed strict market. [Gale–Shapley, Theorem 2](https://uvammm.github.io/docs/gale-shapley.pdf) · [Roth, matched-set invariance](https://web.stanford.edu/~alroth/papers/1986_E_On_the_Allocation.pdf)

Compute

$$
C_{\rm DA}=\min_{A\ \mathrm{successful}} c(A),\qquad
C_G=\min_{\substack{A\ \mathrm{successful}\\ H_G(D_p(A))=H_G(M_E)}}c(A),
\qquad \Delta_G=C_G-C_{\rm DA}.
$$

The support optimum is the cheapest plan whose visible edges contain some full-market stable matching. Compute it as a diagnostic, and compute protection for lower-income renters and for all renters. Each policy has its own baseline $M_0^p$. Check $C_{\rm support}\le C_{\rm DA}\le C_L\le C_{\rm all}\le c(A_{\rm full})$ within each policy. An empty protected group gives a zero premium. Tabulate how often that occurs.

**Implementation and paired algorithm comparison.** For each initially matched $b\in G\setminus H_G(M_E)$, add $\sum_{s\succeq_b M_0^p(b)}z_{bs}=1$ in the support master, summing over acceptable listings. For fixed integer audits the equality selects a face of the stable-matching polytope. A supported full-market stable witness is stable on the visible graph as well. Proposer DA on that graph weakly dominates the witness and therefore satisfies its renter rank guarantees. Keep the full-market blocker oracle, a protection-verified incumbent and an independent rank check. On the algorithm comparison subset run the earlier formulation as a baseline, omitting these rows and enforcing protection with component-prefix failure cuts after DA. Match the incumbents, budgets, seeds and hardware. Report initial-bound quality and end-to-end certification separately. If held-out outcomes have already been inspected, log this algorithm comparison and the mechanism analysis below as later additions to the study.

**Rank severity and a practical protection baseline.** Two repairs can harm exactly the same people and assign them different apartments. Record each renter’s full-list rank (best = 1, unmatched = degree + 1) and compute the difference between their rank under the verified repair and their rank under $M_E$. This difference is nonnegative for a successful repair. Report the fraction with a positive difference, the mean difference in rank positions and the group distributions by feasible degree. At zero degree the difference is zero. Show results separately for renters in the unavoidable-loss set. For the selected plan declare the tie rule in advance. Where all cheapest plans can be enumerated, report the attainable range of these summaries.

For a feasible protected comparator, start reverse-delete from full disclosure and accept a deletion only after rerunning both full stability and group protection checks. Also verify the full-DA prefix-cover baseline, which reproduces $M_E$. Run both for the two protected objectives. Report their costs and times next to the exact method on the same instances. Their verified costs can initialize the upper bound. Charge heuristic initialization to the solver’s time budget.

**Existing benchmark.** Among 160 archived synthetic markets and 614 recorded cost-optimal plans, 155 markets had an unavoidable loss for at least one proposing client. A cheapest audit attained the all-client loss floor in 154 markets. In each of the other six, the cheapest plan attaining the floor cost one audit unit above the ordinary optimum. The premium allows the entire plan to be reoptimized. Of the 154 markets where a cheapest repair attained the floor, five had no cheapest repair reproducing every proposing client’s full-DA partner. These five cases motivate the severity measure. All counts here describe the archived synthetic benchmark, whose lower-access label was assigned randomly.

To reproduce these targets from the team’s archive, run DA on the initial and full graphs of each market. Replay every recorded minimum-cost audit mask, check stability, count strict renter losses relative to the initial assignment and compare the partner vector with full DA. When no cheapest mask attains the full-DA loss count, examine higher-cost masks in increasing cost order until a verified plan does. Save the counts and market IDs with the replication materials.

### A market where protecting renters changes the cost from one audit to $N$

**Proposition.** For each $N\ge1$ there is a unit-cost market with $C_{\rm support}=C_{\rm DA}=1$ and $C_{\rm all}=N$. For a group containing $t$ specified renters of type $a$ below, and no other renters, $C_G=\min(N,1+t)$. The construction gives a result to present even if the NYC premium turns out to be small.

**One copy.** Renters $a,b$ and listings $x,y$ have the following strict rankings. Every acceptable partner ranks above being unmatched.

| Renter | Preferred listings | Listing | Preferred renters |
|---|---|---|---|
| $a$ | $x$ then $y$ | $x$ | $b$ then $a$ |
| $b$ | $y$ then $x$ | $y$ | $a$ then $b$ |

Initially only $ax,ay$ are visible. Renter $a$ gets $x$ and $b$ is unmatched. Pair $by$ blocks. With every edge visible, both renters receive their first choices. The unavoidable-loss set is empty.

**Brokerages and cost.** Take $N$ disjoint copies. All $x_i$ use the same listing brokerage $X$. Every $y_i$ and every renter has its own private firm. Auditing $X$ opens $b_ix_i$ in every copy. Each $x_i$ now holds $b_i$, and $a_i$ goes to $y_i$. Both listings have their first choice, so the response is stable. The initial graph cannot support a full-market stable matching because every $b_i$ lacks a visible partner. Thus support and successful DA repair both cost exactly one. Every $a_i$ loses rank under this repair.

To protect $a_i$, it must keep $x_i$. In any full-market stable matching of this copy both renters are matched, so $b_i$ must get $y_i$. The edge $b_iy_i$ requires one of its two private firms. With $X$ audited, each of the $t$ protected copies therefore costs one more audit. Auditing their $b_i$ firms attains $1+t$. Without $X$, each copy needs at least one private audit to give $b_i$ any available partner. Auditing all $N$ firms of type $b_i$ attains $N$ and gives all renters their first choices. These are the two possible cases. For all-renter protection, the $b_i$ begin unmatched and impose no extra constraint, so the premium is exactly $N-1$. The shared brokerage’s portfolio grows with $N$.

**Five-listing budget.** To realize the experiment’s $\min(5,d_b)$ rule, add five extra listings to each copy. Each extra listing has a dedicated renter who sees only that listing and ranks it first. The listing ranks its dedicated renter first and then $a_i,b_i$ in that order. Both original renters rank all five extras below $x_i,y_i$. Initially $a_i$ sees $x_i,y_i$ and three extras, while $b_i$ sees the five extras. Give extra participants private firms. Every extra listing and its renter must be matched together in any stable response on the visible graph, since their mutual first-choice edge is always visible. Proposing with the dedicated renters first reduces DA to the two-by-two argument. The costs above follow unchanged. This is an admissible shortlist configuration. Its prevalence under any particular recommender is an empirical question.

**Verification and application.** For $N=1,\ldots,5$, the project’s DA and full-market blocking code reproduced the cost formula for every subset of renters of type $a$, in both versions. The check used 10,912 evaluations across all subsets of the cost-relevant firms, with the other audits collectively off and on. The two-case proof establishes the result for general $N$. Include this family in the tiny-market regression suite. For the existing NYC stage-3 runs, show the positive-premium share and solver bounds within terciles of the largest brokerage’s portfolio share, using development cutoffs and keeping market sizes separate. Report sparse or empty bins. This descriptive check asks whether concentration accompanies costly protection in the data. Independent review of the proof and comparison with prior formulations are still needed to establish publication novelty.

**Sparse-market check.** There is also an odd ring of $n=2m+1$ renters with singleton firms, three feasible partners per participant, one initial blocking pair, and costs $C_{\rm DA}=1$, $C_{\rm all}=m+1$. A version supports a five-listing exposure budget. Use $n=3,5,7$ as regression cases with expected protected costs 2, 3 and 4. The construction, proof, protected-master derivation, 160-market bound comparison and verifier travel with the companion IJCAI paper audit.

This motivates one secondary analysis on the existing held-out audit sample. For markets with exactly one initial hidden blocker, report the denominator and distribution of the premium interval with market size and selection policy. Audit each endpoint’s firm separately and record full stability and the number of displaced renters for each of the two responses. Retain failures and timeouts. This costs two DA replays per qualifying market and tests the chain mechanism in markets where brokerage concentration may be small.

## 4. Set preferences before measuring policy differences

For renter $b$ and listing $j$, set

$$
u_{bj}=w_q(Q_j+0.5\xi_j)-w_p r_j/\mathrm{budget}_b+w_s\min(\mathrm{beds}_j-\mathrm{minbeds}_b,2)-w_d\,\mathrm{distance}_{bj}/5+\sigma_r\epsilon_{bj}.
$$

Distance is in kilometres. Independently draw standard normal $\xi_j$ once per listing and $\epsilon_{bj}$ per feasible pair. The transparent policy uses the deterministic part of this score. Replace the rent-premium quality term in the primary score with the mean of two development-standardized attributes, log square footage and bathrooms. Standardize within borough and bedroom bin (0, 1, 2, 3+), using the citywide same-bin reference when a cell has fewer than 30 usable listings. Impute missing inputs to their reference medians and record missingness. Treat nonpositive square footage as missing. A zero-variance or entirely missing fallback feature contributes zero. Fix $w_q=1,w_s=0.5,w_d=0.5$. Clip observed standardized features to ±3. For distance-missing candidates use the development borough median distance and flag the imputation. Holding features, budget and shocks fixed, a price increase must weakly lower the score while the pair stays feasible.

Use 64 renters and 64 listings per calibration market under ordinary sampling. Fit $w_p\in\{1,2,4\}$ and $\sigma_r\in\{0.5,0.75,1.25\}$ using development markets with full-disclosure DA and shared random draws across all nine settings. Minimize the mean absolute error in the 25th, 50th and 75th percentiles of rent burden, giving each income group equal weight. Compute burden as 12 times monthly rent divided by annual income. Compare simulated asking-rent burden among matched renters with survey-weighted contract-rent burden among positive-income, recent-mover ACS households whose observed contract-rent burden is feasible under the same cap. Break ties by smaller $w_p$, then smaller $\sigma_r$. Use 20 calibration seed blocks across the 15 development cells, disjoint from pilot runs. Publish all nine fits, unconstrained ACS burden quantiles, and the share the hard cap excludes. A target median of 52% lies outside the support of a 40%-cap model. Seal the calibration results, selected specification, data transforms and analysis code before scoring the evaluation donors. Report their fit alongside the pilot fit. Carry all nine settings into the sensitivity panel.

On the listing side use the supplied score $2.5\min(I/(12r),40/12)+\eta_{\ell b}$ with independent standard normal shocks. Break score ties with a fixed, seeded strict order for each agent. At a 30% affordability cap the income term is constant across eligible renters. Verify identical listing rankings as its coefficient varies with shocks held fixed. At every cap report the saturated share. Record household, listing, pair and policy RNG keys separately. Preserve shared listing shocks and pair tastes across policies. The ACS burden fit constrains some features of demand. Landlord priorities and individual preference orderings remain modeled.

## 5. Build the shortlists

Use $k_b=\min(5,d_b)$ in the primary run, where $d_b$ is full feasible degree. The second budget is $k_b=\lceil0.4d_b\rceil$. For $k_b=d_b$, return the whole set directly. For $d_b=0$, return the empty set. Feed every policy the same feasible candidate pool. DA uses renter preferences restricted to the returned set, regardless of the order of the model’s reply.

| Policy | Rule |
|---|---|
| Uniform | Sample $k_b$ feasible IDs uniformly without replacement using the policy seed. |
| Transparent baseline | Rank candidates by the fitted observable renter score from §4, suppressing both the shared and individual latent shocks. |
| Expensive-first | Take the $k_b$ highest asking rents. This measures the effect of price-based selection in a constructed scenario. |
| Claude | Keep the team’s existing hosted model as the primary AI. Record a pinned version, endpoint, supported decoding settings, prompt hash and run dates in the manifest. |
| Two local models | Replicate with `Qwen/Qwen2.5-32B-Instruct` and `mistralai/Mistral-Small-3.1-24B-Instruct-2503`. Pin weight and tokenizer commits, chat templates and inference engine. |
| Full visibility | Return $E$. It supplies the renter-optimal benchmark, zero initial blocks and zero repair cost. |
