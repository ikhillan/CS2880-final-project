# Exact individual effects, simultaneous effects and partial rollout

The two design records establish the order of work. DESIGN.md was written before inspecting the isolated-switch estimates. ROLLOUT.md was written after those estimates, before measuring partial adoption. The transfer to a winter cohort is a separate test of the scoring intervention.

run.py reads the existing calibrated 100-block rank archive. For every higher-income applicant a C++17 implementation inserts that applicant once for each feasible singleton into a copy of the proposal state reached without that applicant. It checks the labels and ranks, computes the exact conditional expectation over a uniform quota-five list by binomial probabilities, and scores two reporting rules. Actual baseline and final lower-group counts match the crossed H200 records in every 2,400-market, two-score comparison. First-block checks include full DA after the switch and under each singleton. The residual graph with competitor-occupied seats removed is used to verify the incumbent identity theorem on both score endpoints. Forward and reverse order paths verify telescoping. All lower-income lists stay fixed at their original feasible uniform shortlist.

The isolated sum changes one editor at a time against the *same* realized baseline. Its expectation column integrates only over the focal editor's list, fixing everyone else's lists conditional on the market. The joint change updates all competitor lists simultaneously. Each of the three quantities is standardized to the same lower-income denominator per cell before averaging across cells. Individuals can appear in multiple one-at-a-time effects. A sum is therefore a signed count of effects, not a count of distinct people.

rollout.py stratifies by the number of higher-income editors changing their lists. It uses 24 seeded random permutations per market and exact binomial probabilities for independent adoption. Pointwise intervals are 5,000 paired seed-block bootstrap draws, including each market's sampled permutations; small negative early estimates have intervals containing zero. In contrast, the initial derivative is evaluated analytically and full adoption is evaluated exactly on each market. The main paired intervals for isolated and full-effect comparisons use 10,000 block resamples. Both studies use formerly generated market draws and modeled preferences.

After rebuilding the anonymized rank tensor via research/competition-stress/prepare.py, run the commands shown in the archive's root README. Tooling is Python 3, NumPy, pandas, SciPy, and a C++17 compiler. These CPU experiments do not use API keys. Counts contain market-local indices and sums; they do not contain donor IDs, names or addresses.
