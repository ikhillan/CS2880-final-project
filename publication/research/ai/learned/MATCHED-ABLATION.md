# Parameter-matched row model

This follow-up was requested after the original six fits and before examining any outcomes for the new model. Other-renter context is the variable of interest. Retain all 32-wide encoder, head, layer and outside parameters and both residual update layers from the contextual architecture. Replace mean competitor embeddings by the focal edge's own embedding, and listing degree by the focal renter's degree. Each update can still use the renter's rowwise feasible-set mean and degree. No input can depend on any other renter's features. Three independent seeds 8101–8103, 28 epochs, same AdamW, normalization, train and validation blocks, and checkpoint-selection rule as the six original models. Compute paired oracle top-five recovery, NLL, and all-renter DA placements using the same frozen market draws. Treat comparisons with the already studied contextual model as exploratory. Only the uncoordinated top-five decoder is needed to test the representation.
