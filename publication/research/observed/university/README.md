# Chilean university offers and five-program shortlists

The Chilean Ministry of Education publishes anonymized ranked program applications, program-specific selection scores, selection statuses and announced seats. Download the PAES 2024–26 application and program-offer RARs with the script below. The archive includes aggregate outputs and reproducible code; the publisher retains the individual-level records. The data dictionaries are in the same RARs. Python 3.11+, NumPy, SciPy, pandas and a C++17 compiler are sufficient for the primary test. Use libarchive bsdtar for RAR extraction. The actual selection process includes reserved channels, formal admission requirements and ties. Our benchmark covers only the regular channel and scores observable on submitted applications. The study holds those lists fixed as potential choices. Cohort-wide effects of forcing a five-option shortlist were not observed by the ministry.

~~~sh
python fetch.py raw-inputs
OPENBLAS_NUM_THREADS=1 python run.py raw-inputs results
python capacity.py raw-inputs results results/flow.csv
~~~

For the separate recorded-offer neural check run prepare_offer.py raw-inputs features, then train_offer.py for tasks 0–5 with --data features --out fit. The Slurm example expects the feature files in its working directory. The supplied model weights also support offline inference with replay_offer.py. To score the resulting probabilities, use score_offer.py raw-inputs features fit results (run the primary analysis first). The six random seeds/specifications are fixed. Numeric market probabilities, labels and individual rows are not packaged. Files generated during regeneration stay local. PROTOCOL.md precedes the primary outcome; OFFER-TRAINING.md is a disclosed follow-up on the same test cohort. CAPACITY-FOLLOWUP.md documents the flow calculation. The scholarship/staff/family priority fields in the companion K–12 study are unrelated to the program-specific university scores. Do not pool either type of applicant across rules for statistical inference.

Recovery uses full-report DA partners conditional on placement or, where labeled, administrative regular offers conditional on observing an offer. Uniform coverage on both label sets has exact expectation sum_i min(1,k/d_i) divided by the number of recipients. counts.csv uses 64 simulated draws for all uniform columns. In the manuscript uniform coverage uses the exact expectation where available. DA placement is the total number of assignees divided by the entire regular cohort. Report the uniform mean and Monte Carlo uncertainty conditional on that cohort. A submitted program status of 26 can mean that the applicant was already selected higher in their list; the post-hoc positive-score reconstruction checks how much reliance on that status changes the candidate graph. Percentages cover full grades/schools/programs as described in the paper. No trial or randomized deployment was conducted.
