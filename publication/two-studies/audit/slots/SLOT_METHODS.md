# Stability-preserving slot changes

We allow each applicant to choose from the union of the two old and proposed lists, or from all eligible options. In both cases the old contract (if any) and current-school entitlement (if any) are compulsory. The list has its original total size and the entitlement is included outside the discretionary quota. Every new exposed pair must pass the blocking test against the fixed old assignment. Capacities, preferences, priorities and both proposed policies stay fixed. The objective is additive across displayed edges. Conditional on the fixed old assignment, sorting permissible edges by their scores is exact. Applicant-proposing DA on the resulting graph weakly improves all participants relative to the old assignment and the set of recipients is identical. Historical or full-DA reference targets can be used to compute separate hindsight ceilings. An offer outside the eligible school graph can never be shown and contributes zero to policy coverage. Sixty-four historical offers fall in this category across 2022–25.

The score-based school comparison uses the original floating-point scores of the frozen 2019 rank-informed fitted model stored after the input arrays in each numeric market file. Under equal scores, prefer an option already in the proposed list, then one in the baseline list, then the earliest edge in the input. With no stability filter or required baseline contract, the algorithm exactly reproduces the original candidate policy under the quota and entitlement rule. The school input orders each pupil’s choices by reported preference, including the protected current school where applicable. In housing the cached model supplies a five-option set and no scores on options outside it. The objective awards one point per retained model option. The same tie-breaking rule applies, with input edges ordered by applicant and then listing index. Thus the all-edges and union score-based housing policies coincide, although the hindsight ceilings differ. This rule uses the simulated renter and landlord rankings to test blocking and cannot be marketed as a field-ready system. Neither score-based rule sees full-list DA partners or historical offer labels. The results are an exploratory follow-up performed with previous outcomes known.

All reported numbers are raw applicant counts. The housing totals pool 240 markets per supply design and do not use the borough/month weights of the original simulated treatment effect. The union and full-pool results are two redesigns on the same original people, so their counts must not be added. The oracle gain counts additional reference edges over A, with all existing hits retained. Columns ending in 'reference_edges' refer to targets in the eligible graph. The 'missed' counts partition exactly into 'outside_pool', 'blocks' (within the specified candidate pool), 'no_slot' (remaining eligible target with no free slot) and 'slot_oracle_gain'. 'candidate_gain' is the original unprotected candidate policy B relative to A. 'slot_score_gain' is the actual change in hits after reranking edges without using labels. 'proposed_new_options_kept' counts new B edges retained. 'improved_assignments' counts original recipients strictly improving rank in DA.

Set REPO to the full project root and initialize the NYC development catalogs as described in the two-study README. Use the same prepared national arrays as for the paper: NUMERIC for 2022–23 and LATER for 2024–25. The driver imports the pre-existing school solver from publication/research/policy/equity/transitions.py. It reads original masks, scores, capacities, ranks, and assignments. It recomputes baseline DA and both score-based policies in all four school cohorts and all 480 NYC markets, checks all recipients and ranks, directly verifies the stable-witness constraints on every score-based and hindsight solution, and confirms each quota and entitlement. The NYC full reference and both options lists are regenerated from the cached choices. The exhaustive test uses direct two-by-two blocking and all alternative menus as an independent small-instance oracle over four capacity profiles, all strict orderings, and all subsets of baseline edges as protected options. It includes mixed-sign scores and single-edge indicator scores.

```sh
python slot_repair.py --repo "$REPO" --site school --numeric "$NUMERIC" --years 2022 2023 --out school-a.csv
python slot_repair.py --repo "$REPO" --site school --numeric "$LATER" --years 2024 2025 --out school-b.csv
python slot_repair.py --repo "$REPO" --site housing --out nyc.csv
python verify_slots.py > slot-exhaustive.json
```

The full-information positive control requires the calculated full-list DA outcome, keeps each recipient’s full-list contract and any entitlement, and fills remaining slots using the same scores and tie-breaking as the constrained design. This control reruns DA and verifies the same recipients and weakly better ranks relative to full-list DA. The target in the 'history_full_control_coverage' column was never used to construct the control. A gain 'vs_b' uses the original unconstrained rank-informed school or Haiku rental policy as its comparator. These control columns repeat across pool rows because the control uses all eligible options and each number is counted only once per panel. The control can change the recipient set relative to A and B. Its timing presumes knowledge of final preferences and realized priorities, which would be unavailable for advice prior to school submission and unobserved in the rental data.

An independent row-by-row C++ implementation reconstructs the menus using the original seed and calls the serial DA checker. It reproduces 56 reported national cells, including the historical and full-partner oracle, repaired-score gains, rank gains and both full-information control comparisons. To repeat, compile with the original paper’s school source included. The four archived check CSVs are the output of individual invocations.

```sh
c++ -std=c++17 -O2 -I "$REPO/publication/research/observed/school" verify_school_slots.cpp -o /tmp/verify_school_slots
```
