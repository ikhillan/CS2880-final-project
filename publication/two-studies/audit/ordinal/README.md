# Housing assignment ranks

From this directory, run `python rental_ranks.py --repo "$REPO" --out replay` after preparing the development catalogues and saved Haiku cache following the paper README. Rank is one-based among the household's entire feasible set with the original taste realization. An unplaced household counts as a failure at all 64 cutoffs. Both policies are reapplied to the same instance. `rental-rank-counts.csv.gz` records all 64 cumulative cutoffs by market, and `rental-rank-transitions.csv` counts individual improvements/deteriorations, split by whether the person enters or exits placement. `rental-rank-summary.csv` aggregates endpoints and pointwise paired 95% seed-block intervals. The final cutoff and its interval reproduce the original geographically standardized placement comparison to numerical precision. Raw instance counts are provided separately; households can recur across draws. The expanded rank analysis was exploratory.
