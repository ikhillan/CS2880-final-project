# What the lottery result adds

The defensible claim is a complexity boundary for choosing quota-constrained displays against a specified list of market-wide priority scenarios. A single common menu must make each draw’s own baseline assignment stable in enough draws. With zero tolerated failures, all eligibility conditions can be combined row by row. With a fixed positive percentage of failures allowed, choosing which draws to sacrifice is NP-complete, even when actual DA displacements coincide with certificate failures. Neither super-stability, the global scenario criterion, nor the combinatorial cost of the union of failed scenarios is new by itself.

## Assumptions that affect interpretation

- A finite equally weighted list represents a distribution over specified profiles. Appending multiple labeled draws with identical comparisons is permitted. Adding a cyclically permuted block of private-seat applicants makes priority profiles pairwise distinct if necessary.
- The parameterized conclusion is W[1]-hard in the *number* of allowed failures when the tolerance varies. The exact enumeration is polynomial for each fixed number of allowed failures; its exponent depends on that number. At fixed percentage and varying support size the decision problem is NP-complete. At fixed percentage, the support size itself is bounded in terms of the absolute number of failures, so one cannot conclude parameterized hardness for that restriction from this reduction.
- An explicit panel is narrower than a uniform draw from all permutations. Under unbiased pair comparisons and a constant baseline assignment, a possible failure already has probability at least one half. Under a draw-specific baseline, a single edit can create actual losses on arbitrarily rare draws. The example in the paper exhibits exactly that event.
- Positive risk for a lost certificate need not entail an actual loser in a general market. On the reduction it does. The polynomial zero-failure algorithm is for baseline stability; its optimality as a method for preserving people’s placements alone does not follow. An applicant whose old program loses a stable witness might move to a better seat while every recipient stays placed.
- One-sided binomial uncertainty from fresh uniform draws concerns a frozen rule in a fixed market and a specified priority law. Assess per-draw indicators for at least one loss, and gross losses per draw separately. The same shocks must be shared by the baseline and challenger. Historical SAE data need not obey a redrawn or common lottery law.
- The code enumerates DA outcomes and tests stability independently of the claimed graph identity. This corroborates the constructions on finite examples. The analytical proof gives the general result.
